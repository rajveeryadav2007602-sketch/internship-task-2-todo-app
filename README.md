# Daymark — To-do list

A polished, responsive task list built with plain HTML, CSS, and JavaScript. Each task can include a clear description, category, due date, and priority so the next step is easy to understand. Tasks are saved in the browser with `localStorage` and stay on the same device and browser after a refresh.

## Run it

1. Extract the project ZIP.
2. Open `index.html` in a modern web browser.
3. Try the sample tasks, then add, complete, filter, or remove tasks. No installation or build step is needed.

## Features

- Add tasks with optional descriptions, categories, and due dates, plus low, medium, or high priority
- Five student and internship sample tasks with actionable next steps, different priorities, due dates, and a completed example
- Add, complete, and remove tasks
- All, Active, and Done filters
- Active-task count and clear-completed action
- Automatic local saving and loading
- Responsive layout, keyboard focus styles, accessible labels, and screen-reader announcements
- Graceful handling of unreadable or unavailable browser storage

The starter tasks are added once when the app first opens in a browser. Removing them or clearing the list is remembered, including after refresh.

## Project files

- `index.html` — semantic app structure and author details
- `style.css` — responsive visual design
- `script.js` — interactions, sample tasks, and localStorage persistence

The Google Fonts link is optional; system fallbacks keep the app usable when offline.
